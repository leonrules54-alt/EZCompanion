🛡️ Installation Help — seeing a security warning?

🪟 Windows SmartScreen — "Windows protected your PC"

Click the "More info" text link on the blue warning box, then click the "Run anyway" button that appears at the bottom.

🪟 Windows 11 Smart App Control (SAC)

If Windows blocks the app entirely, go to Windows Security → App & browser control → Smart App Control settings and switch it off — or use our portable .zip instead (unzip and run, nothing to install).

🍎 macOS Gatekeeper

Right-click the .dmg or app icon, select Open, then click Open again in the pop-up dialog. After that it opens normally.
